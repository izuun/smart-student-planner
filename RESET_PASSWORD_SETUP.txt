NEW environment variable needed for the password reset feature:

RESEND_API_KEY=your-resend-api-key

How to get one:
1. Go to https://resend.com and sign up (free tier is generous - 3,000 emails/month, 100/day)
2. Go to API Keys in the dashboard, click "Create API Key"
3. Copy the key, add it to your .env.local AND to Vercel's Environment Variables

Optional (only needed once you verify your own sending domain in Resend):
RESEND_FROM_EMAIL=Smart Student Planner <noreply@yourdomain.com>

Without RESEND_FROM_EMAIL set, emails send from Resend's shared test address
(onboarding@resend.dev), which can ONLY deliver to the email address you
signed up to Resend with. This is fine for testing password reset yourself,
but won't work for other real users until you verify a domain.
